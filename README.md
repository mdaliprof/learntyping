# Typing Trail

A single-file web app that teaches kids to touch type.

- 16 levels, two keys at a time: home row, top row, bottom row, then words and capital-letter sentences
- On-screen keyboard colored by finger, with hand diagrams showing which finger to use
- Star ratings from accuracy, plus speed and mistake counts
- Balloon Pop game using the letters learned so far
- Progress saved in the browser (localStorage); works best with a physical keyboard

## Run
Open `index.html` in a browser. No build step. (Fonts load from Google Fonts when online.)
